# Skills

These files are lightweight operational playbooks for recurring pipeline tasks.

## Included skills
- [Cost Checking](cost-checking.skill.md)
- [Metrics Scorecard](metrics-scorecard.skill.md)

## What a skill file should contain
- Purpose and trigger conditions
- Required inputs and produced outputs
- Deterministic workflow/checklist
- Formulas and threshold definitions
- Guardrails and edge-case handling
- Audit/log payload examples
- Operational targets

## How to use
1. Pick the skill for the current task.
2. Follow steps top-to-bottom.
3. Emit structured logs as described.
4. Link outcomes into weekly scorecard reporting.
